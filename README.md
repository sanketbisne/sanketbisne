## About Me

I am a **Google Developer Expert (GDE) in Google Cloud Platform (GCP)** and a **Sr. Enterprise AI Engineer at Motive** (previously **Senior DevOps Engineer at Lloyds Banking Group**), based in India.

My work bridges **enterprise cloud infrastructure** and **Agentic AI**—building scalable Kubernetes (GKE) ecosystems, resilient CI/CD and GitOps pipelines, and production-ready autonomous AI agents using **Google ADK**, **Model Context Protocol (MCP / FastMCP / WebMCP)**, **LangGraph**, and **Gemini**.

## Featured Open-Source Projects

### Agentic AI, ADK & MCP
- [**`adk-webmcp-storefront`**](https://github.com/sanketbisne/adk-webmcp-storefront) — Browser-native AI agents built with **WebMCP** (`navigator.modelContext` + Declarative HTML Forms), **Google ADK**, deterministic Python safety guardrails, and Google Cloud Agent Runtime telemetry.
- [**`scalfod-langgraph-agentscli`**](https://github.com/sanketbisne/scalfod-langgraph-agentscli) — Ship pure LangChain and LangGraph agents to Google Cloud Run using the Google Agents CLI Extension System, with ReAct + Self-Critique graphs, Vertex AI Evals, FastAPI A2A server, and an SBOM deploy gate.
- [**`vllm-gcp-cloudrun`**](https://github.com/sanketbisne/vllm-gcp-cloudrun) — Production blueprint for **vLLM on Google Cloud Run** with NVIDIA L4 GPU, GCS FUSE weight streaming, and an Enterprise RAG Dashboard.
- [**`starbrew-reserve-cloudsql-saas`**](https://github.com/sanketbisne/starbrew-reserve-cloudsql-saas) — Global retail SaaS, Voice AI Barista, and smart context recommender built on Cloud Run and Cloud SQL (PostgreSQL 15).
- [**`adk-k8s-gcs-agent`**](https://github.com/sanketbisne/adk-k8s-gcs-agent) — AI agent built with Google ADK for Kubernetes diagnostics (pods, deployments, logs) and Google Cloud Storage health reporting.
- [**`gcs-mcp-server`**](https://github.com/sanketbisne/gcs-mcp-server) — Model Context Protocol (MCP / FastMCP) server giving LLM agents safe, programmatic tools for Google Cloud Storage.
- [**`Ai-learning-for-all`**](https://github.com/sanketbisne/Ai-learning-for-all) — Open learning repository for anyone starting AI from scratch.

### Cloud, Kubernetes & Observability
- [**`omni-spanner`**](https://github.com/sanketbisne/omni-spanner) — Google I/O Connect repository showcasing **Cloud Spanner Omni on GKE** from deployment and IaC configuration to sample apps, SQL queries, and observability.
- [**`gemini-grafana-gke-observability`**](https://github.com/sanketbisne/gemini-grafana-gke-observability) — Kubernetes observability sandbox on GKE integrating **Grafana, Prometheus, and Gemini CLI** via MCP for conversational incident triage.
- [**`InsightFlow-agent-cli`**](https://github.com/sanketbisne/InsightFlow-agent-cli) — Infrastructure and agent CLI automation workflows.
- [**`dbt-repository`**](https://github.com/sanketbisne/dbt-repository) — Proof-of-concept dbt data transformation pipeline.
